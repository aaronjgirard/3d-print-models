Summary:
Still adding more designs / remix descriptions...This is a collection of many different marble tracks compatible with Marbleworks Grand Prix marble set, for which getting replacement parts is difficult. Additionally there's a bunch of new designs cooked up to make more creative marble mazes. Marble Run Collection by muilenta was an inspiration, but the parts there were the wrong dimensions for the marbleworks originals and converting all of them proved more work than expected, so mostly new designs were made from scratch. Currently the exception is the Wiggle design which we reused the Marble Run Bottom Out ramp section with modifications.The connectors are 27mm across with 1.5-2.0mm tapered wall diameters. Most designs have been battle tested with a 2-3 year old (and a few adults). It took a couple generations of testing to get connectors that were strong, matched the original parts, and didn't shoot marbles out like an airsoft gun. I'll create remixes for each robust individual design, but wanted to post a larger WIP page for all the parts to be consumed together.
