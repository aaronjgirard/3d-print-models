# Spirit dragon and egg

Updated 2026-11-22 21:36 MST

A spirit dragon and a two-part egg (top and bottom, wider base), set up in OrcaSlicer for the SV06 ACE.

| file | what |
|---|---|
| `Spirit_Dragon_v9_5.3mf` | the dragon, one plate (`Spirit_Dragon_v9_5.stl`) |
| `Large_Egg_wider_base.3mf` | the egg, two plates (`EggTop`, `EggBottom`) |
| `_3plate_project_backup.3mf` | all three plates in one project |
| `presets/` | OrcaSlicer user presets used for these prints |

## Presets
| preset | based on | changes |
|---|---|---|
| `0.20 Dragon silk @SV06 ACE` | `0.20mm Standard @Sovol SV06 ACE` | 3 walls, 15% gyroid |
| `0.20 Egg PETG @SV06 ACE` | `0.20mm Standard @Sovol SV06 ACE` | 3 walls, 15% gyroid |
| `Silk PLA @SV06 ACE` | `Generic PLA @Sovol SV06 ACE` | nozzle 220 C, bed 60 C |
| `PETG @SV06 ACE` | `Generic PETG @Sovol SV06 ACE` | nozzle 240 C, bed 80 C |

Import the presets in OrcaSlicer (File > Import > Import Configs) before opening the projects.
